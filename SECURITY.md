# Security policy

Report a vulnerability that affects this tap through the main project's policy:
[oc-model-manager security policy](https://github.com/SunnyJayaRaju/oc-model-manager/blob/main/SECURITY.md).

In short: use [GitHub Security Advisories](https://github.com/SunnyJayaRaju/oc-model-manager/security/advisories/new)
for sensitive reports, or open an issue for non-sensitive ones. There is no bug
bounty. Response times are best-effort.

For a formula problem that is not security-sensitive (wrong checksum, failed
install, stale version), open an issue in this repository instead.
