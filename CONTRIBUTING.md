# Contributing

- Formula problems (install, upgrade, checksum, version mismatch): open an issue in this repository.
- ocprobe tool problems (probe, validate, apply, doctor): open an issue in [oc-model-manager](https://github.com/SunnyJayaRaju/oc-model-manager).
- `Formula/ocprobe.rb` is generated from oc-model-manager releases, so version bumps are not edited here by hand.
